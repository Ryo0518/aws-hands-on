# Mission 1：S3静的Webサイト構築

## 1. シナリオ・要件

### シナリオ
AWSを利用して、静的なWebサイトを公開する。

### 要件
- Amazon S3を利用する
- HTMLファイルをS3にアップロードする
- S3の静的ウェブサイトホスティング機能を利用する
- インターネットからWebサイトへアクセスできるようにする
