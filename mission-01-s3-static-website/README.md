## 6. 発生した問題と解決方法

### 403 Forbiddenが発生

S3静的ウェブサイトエンドポイントへアクセスした際、
403 Forbiddenが発生した。

### 原因

S3バケットのパブリックアクセス設定と、
バケットポリシーによるオブジェクトの読み取り権限を確認する必要があった。

### 対応

- パブリックアクセスブロック設定を確認
- バケットポリシーを設定
- `index.html` の読み取り権限を確認

設定後、静的Webサイトエンドポイントから
正常にアクセスできることを確認した。
